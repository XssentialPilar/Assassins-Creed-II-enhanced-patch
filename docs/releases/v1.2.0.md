Version 1.2.0 updates keyboard and mouse prompts and adds the WASAPI/XAudio2 gameplay output bridge for **Assassin’s Creed II on Steam for Windows**, app **33230**, build **1843459**.

## Input prompts

- Keycaps in Controls and the gameplay action HUD follow the active assignments. Rebind an action in Controls to see the new keycap immediately.
- All 24 binding rows use the same anti-aliased keycap artwork. Keyboard and mouse prompts are dark and translucent at rest and white when pressed. Left Shift, right Shift, and Space have distinct symbols.
- **View input prompts** in the installer shows the released and pressed artwork from its bundled patch. [Complete keyboard and mouse layout](https://raw.githubusercontent.com/XssentialPilar/Assassins-Creed-II-enhanced-patch/v1.2.0/docs/screenshots/keyboard-layout-v1.2.0.png)

## Gameplay audio

WASAPI detects the Windows output format and XAudio2 plays the game’s existing Wwise mix. DirectSound handles compatibility fallback and Bink video audio. Exclusive DirectOut supports manually mapped output streams of 1 to 24 channels where the interface accepts the format. The game supplies its original six-channel mix. Acoustic portals and per-source binaural stereo remain in development. [Output map, diagnostic commands, and hardware checks](https://github.com/XssentialPilar/Assassins-Creed-II-enhanced-patch/blob/v1.2.0/docs/audio-outputs.md)

## Install

- **Windows setup.** Extract `AC2-Enhanced-Patch-v1.2.0-Setup-win-x64.zip` and run the versioned setup executable. Keep `AC2EnhancedPatch.Payload.dll` in the same folder. Setup offers 25 languages and can restore the previous installation.
- **Manual installation.** Back up any previous patch DLLs and extract `d3d9.dll` and `SDL3.dll` from `AC2-Enhanced-Patch-v1.2.0-win32.zip` beside `AssassinsCreedIIGame.exe`.

Close the game before installing. SHA-256 checksums for both ZIP files are under **Assets**. [Installation guide](https://github.com/XssentialPilar/Assassins-Creed-II-enhanced-patch/tree/v1.2.0#installation)
